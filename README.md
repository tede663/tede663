# Наша маленькая история ❤️

Готовый стартовый проект на C + SDL2 для Emscripten/WebAssembly.

## Что уже есть

- стартовый экран, чтобы браузер разрешил музыку после касания;
- управление тапом/мышью и стрелками на Mac;
- пиксельный персонаж 12×16, нарисованный массивом строк;
- комната;
- 1 главный подарок-воспоминание;
- всплывающие окна с текстом;
- дверь после сбора всех воспоминаний;
- финальный экран;
- подготовлена загрузка кириллического TTF;
- подготовлена загрузка музыки OGG;
- ассеты из присланных изображений уже лежат в `assets/` (BMP, поэтому SDL_image не нужен).

## Перед первой сборкой

1. Установи Emscripten:
   `brew install emscripten`

2. Проверь:
   `emcc --version`

3. Положи шрифт с кириллицей:
   `assets/NotoSans-Regular.ttf`

4. Положи песню:
   `assets/music.ogg`

## Сборка

Из папки проекта:

```bash
./build.sh
```

Результат появится в:

```text
build/index.html
build/index.js
build/index.data
...
```

## Локальный запуск

```bash
cd build
python3 -m http.server 8000
```

Потом открой `http://localhost:8000`.

Не открывай `index.html` двойным кликом: для загрузки `.data` нужен HTTP-сервер.

## GitHub Pages

После сборки загрузи содержимое папки `build/` в репозиторий и включи Pages для нужной ветки/папки.

## Где менять личные тексты

В `main.c` найди:

```c
static Memory memories[3]
```

Текст поздравления находится в `static Memory memories[1]`.

Финальное сообщение находится в функции:

```c
static void draw_final(void)
```

Имя Маша и финальный текст уже подставлены.

## Важно

Музыку лучше использовать в `.ogg`: это обычно проще для браузерной сборки через SDL_mixer.
